FAQ

Apa itu Smart Routing?
Smart Routing adalah strategi menggunakan model AI yang berbeda untuk setiap tahap produksi. Riset menggunakan model murah, Writer menggunakan model berkualitas tinggi, dll. Hasilnya: kualitas premium dengan biaya optimal.
Bagaimana Fair Use Policy bekerja?
Setiap paket memiliki batasan wajar per bulan (misal: 80 artikel untuk Enterprise). Jika melewati batas, dikenakan overage fee Rp 8.000/artikel. Ini untuk memastikan kualitas server tetap optimal bagi semua pelanggan.
Apakah konten benar-benar original?
Ya. Sistem memiliki 5 agen yang bekerja berurutan: Riset → Verifikasi → Writer → Editor → Publisher. Setiap tahap memastikan konten original, terverifikasi, dan berkualitas.
Bagaimana cara kerja paket Enterprise?
Paket Enterprise (Rp 2.499.000/bulan) mencakup 80 artikel/bulan dengan Fair Use Policy. Jika Anda membutuhkan lebih, dikenakan overage fee Rp 8.000/artikel. Ini memastikan Anda tetap mendapatkan kualitas premium tanpa khawatir biaya membengkak.
Apakah ada jaminan uang kembali?
Ya. Kami memberikan garansi 14 hari uang kembali jika Anda tidak puas dengan kualitas layanan. Tidak ada pertanyaan, tidak ada ribet.
