1. Executive Summary

NaraGen Lab adalah sistem produksi konten berita berbasis AI yang menggunakan arsitektur multi-agent pada platform Hermes Agent. Sistem mengotomatisasi seluruh alur jurnalistik — riset, verifikasi fakta, penulisan, editing, publikasi — melalui 5 agen AI yang berinteraksi transparan dalam satu grup Telegram.

🔍 Transparansi Penuh

Seluruh proses editorial terlihat oleh pemilik di grup Telegram.

✍️ Keaslian Terjamin

Anti-plagiat dan humanisasi konten bawaan di setiap pipeline.

⚖️ Keamanan Hukum

Gerbang hak cipta dan monetisasi terintegrasi.

💰 Efisiensi Biaya

Menggunakan model AI gratis/tier murah dari Nous Research.

2. Latar Belakang & Masalah

2.1 Masalah

  • Produksi konten berkualitas tinggi memakan waktu dan biaya besar.
  • Konten AI generik sering terdengar robotik dan rentan plagiarisme.
  • Verifikasi fakta sering diabaikan dalam produksi konten cepat.
  • Kurangnya transparansi dalam pipeline konten otomatis.

2.2 Solusi

Sistem multi-agent di mana setiap agen memiliki peran spesifik dengan "gate" kualitas wajib sebelum pekerjaan diteruskan ke tahap berikutnya.

5. Ruang Lingkup (Scope)

5.1 In Scope

  • Pipeline produksi berita otomatis (5 agen)
  • Integrasi Telegram sebagai antarmuka utama
  • Verifikasi fakta dengan gate wajib
  • Humanisasi konten anti-AI-sounding
  • Anti-plagiat dan hak cipta
  • Format multi-platform (website, X, LinkedIn, Instagram)
  • Watchdog dan monitoring
  • Template SOUL.md yang dapat dikustomisasi

5.2 Out of Scope

  • Sistem manajemen pembayaran/penagihan
  • Aplikasi mobile native
  • Portal web kustom (integrasi eksternal opsional)
  • Multi-bahasa (fokus Bahasa Indonesia)

7. Spesifikasi Fungsional

7.1 Module: Research Agent (Raka)

AturanKeterangan
InputPerintah topik dari Orkestrator
ProsesWeb search → ringkasan poin kunci → triangulasi sumber
OutputPaket sumber: URL, key facts, angle suggestion
GateMinimal 2 sumber independen
PersonaAnak Jakarta energik, bahasa gaul

7.2 Module: Fact-Check Agent (Sari)

AturanKeterangan
InputPaket sumber dari Raka
ProsesVerifikasi: nama, angka, tanggal, institusi, kutipan
OutputStatus: aman / revisi / stop
GateStatus harus aman untuk lanjut
ReferensiDuke Reporters' Lab, IFCN, C.R.A.A.P. test

7.3 Module: Writer Agent (Dimas)

AturanKeterangan
InputFakta terverifikasi dari Sari
ProsesMenulis 500-800 kata, inverted pyramid, original
OutputArtikel + thread X + LinkedIn + IG + hashtags
GateTidak boleh menambah fakta tanpa sumber
ReferensiStrunk & White, Inverted Pyramid, Show don't tell

7.4 Module: Editor Agent (Maya)

AturanKeterangan
InputDraf artikel dari Dimas
Gate 1Humanisasi: bunuh pola AI
Gate 2Anti-plagiat: rewrite jika similarity > 15%
OutputArtikel final + editorial notes + verdict
ReferensiSPJ Code of Ethics, AP Stylebook

7.5 Module: Publisher Agent (Ari)

AturanKeterangan
InputArtikel final dari Maya
ProsesFormat untuk web, sosmed, audio; SEO optimization
OutputPaket final: SEO title, slug, meta, semua format
GateJudul GREGET tapi tidak clickbait palsu
ReferensiNeil Patel, Backlinko, Google E-E-A-T
