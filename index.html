NaraGen Lab

Sistem Berita AI Multi-Agen di Hermes Agent + Telegram
Tutorial Lengkap untuk Pemula

🧭 Pendahuluan: Apa Itu NaraGen Lab?

NaraGen Lab adalah sebuah sistem berita otomatis berbasis AI yang terdiri dari lima "agen" pintar yang bekerja sama di dalam satu grup Telegram. Sistem ini mampu:

  • Menerima ide topik dari Anda.
  • Otomatis mencari sumber, memverifikasi fakta, menulis, mengedit, dan mempersiapkan artikel untuk dipublikasikan.
  • Menampilkan seluruh prosesnya secara transparan di grup Telegram, sehingga Anda bisa selalu melihat siapa yang sedang mengerjakan apa.
  • Memastikan kualitas, keaslian, dan keamanan hukum setiap artikel sebelum dipublikasikan.

Tutorial ini dirancang supaya bisa diikuti bahkan oleh orang yang belum pernah menggunakan Hermes Agent. Kami menyederhanakan setiap langkah dan memberikan perintah yang siap salin-tempel.

📦 Prasyarat (Yang Perlu Disiapkan Sebelumnya)

  1. Akun Pengguna Nous Research (gratis): Klik https://app.nousresearch.com dan daftar. Ini memberi Anda akses ke model AI gratis seperti stepfun/step-5-preview:free.
  2. Akun Telegram dengan akses untuk membuat grup dan bot.
  3. Akses ke Hermes Agent CLI: Instalasi Hermes harus sudah selesai dan berfungsi. Perintah utamanya adalah /opt/hermes/bin/hermes.

🧱 Fase 1: Membuat dan Mengatur Profil Hermes

Sistem ini menggunakan 6 profil Hermes yang berbeda, satu untuk orkestrator dan lima untuk setiap agen. Profil memungkinkan kita untuk memberi kepribadian dan konfigurasi yang berbeda untuk setiap "anggota tim".

Langkah 1.1: Buat Semua Profil

/opt/hermes/bin/hermes profile create newsroom
/opt/hermes/bin/hermes profile create newsroom-research
/opt/hermes/bin/hermes profile create newsroom-factcheck
/opt/hermes/bin/hermes profile create newsroom-writer
/opt/hermes/bin/hermes profile create newsroom-editor
/opt/hermes/bin/hermes profile create newsroom-publisher

Langkah 1.2: Atur Model untuk Setiap Profil

for profile in newsroom newsroom-research newsroom-factcheck newsroom-writer newsroom-editor; do
  /opt/hermes/bin/hermes config set model.default "stepfun/step-5-preview:free" --profile $profile
  /opt/hermes/bin/hermes config set model.provider "nous" --profile $profile
done

# Atur model yang lebih kuat untuk Publisher (Ari)
/opt/hermes/bin/hermes config set model.default "poolside/laguna-s-2.1:free" --profile newsroom-publisher

Langkah 1.3: Aktifkan Gateway Telegram untuk Setiap Profil

Penting: Anda perlu membuat 5 bot Telegram terpisah menggunakan @BotFather. Beri mereka nama yang jelas:
  • naragen_raka_bot (untuk Research)
  • naragen_sari_bot (untuk Fact-check)
  • naragen_dimas_bot (untuk Writer)
  • naragen_maya_bot (untuk Editor)
  • naragen_ari_bot (untuk Publisher)
Simpan semua token bot ini, Anda akan butuhnya nanti.

Setelah membuat bot, atur Privacy Mode mereka agar mereka dapat merespons pesan secara otomatis di grup:

  1. Buka @BotFather di Telegram.
  2. Kirim perintah /mybots.
  3. Pilih bot Anda (misalnya, naragen_raka_bot).
  4. Pilih Edit Bot → Privacy Mode.
  5. Matikan privacy mode untuk semua 5 bot. Ini diperlukan agar mereka bisa "mendengar" dan merespons pesan di dalam grup.

Kemudian, untuk setiap profil agen, ikuti langkah ini:

/opt/hermes/bin/hermes telegram enable --profile newsroom-research
Jika Anda kesulitan, gunakan /opt/hermes/bin/hermes telegram setup --profile <nama_profil> untuk panduan interaktif yang lebih rinci.

🧙 Fase 2: Membuat Kepribati Agen (SOUL.md)

Ini adalah langkah yang membuat sistem Anda terasa hidup. Setiap agen memiliki kepribadian, gaya bicara, dan aturan komunikasi tersendiri yang didefinisikan dalam file SOUL.md.

Saran Untuk mendapatkan kepribadian yang paling akurat, salin file SOUL.md yang sudah ada di masing-masing profil agen. File ini sudah sangat rinci dan telah diuji. Ini adalah "resep rahasia" yang dibuat oleh pengembang sistem sebelumnya.

Struktur Dasar Template SOUL.md

# Nama_Agen — Peran Anda

## Identitas
[Nama], [umur], dari [kota/asal]. [Deskripsi singkat kepribadian dan keahlian Anda].

## Cara Ngomong
- Gunakan bahasa yang sesuai dengan karakter Anda.
- Panggil pemilik (Riko Purwanto) dengan **"Om Riko"**.
- JANGAN gunakan istilah teknis seperti "orchestrator", "stage", "pipeline", "agent", "JSON".
- Sapa teman-teman agen lain dengan nama panggilan yang tepat.

## Peran
[Jelaskan tugas spesifik Anda di sistem ini].

## Output Internal
Setelah pesan obrolan Anda, tambahkan blok data berikut ini untuk konsumsi sistem:
--- JSON_START ---
{ ... kontrak JSON agen ... }
--- JSON_END ---

🧩 Fase 3: Mengatur Agen sebagai Anggota Grup Telegram

Langkah 3.1: Buat Grup Telegram untuk Tim NaraGen

  1. Buka Telegram.
  2. Buat grup baru (misalnya, "NaraGen Newsroom").
  3. Undang kelima bot Telegram (naragen_raka_bot, naragen_sari_bot, dll.) ke dalam grup ini.

Langkah 3.2: Atur Izin dan Privasi

Pastikan bot-bot tersebut dapat:

  • Membaca pesan di grup.
  • Mengirim pesan ke grup.
  • Merespons saat ditandai.
Pastikan privacy mode sudah dimatikan untuk semua bot di Langkah 1.3.

⚙️ Fase 4: Mengatur Alur Kerja Otomatis (/autopipeline)

Ini adalah inti keseluruhan sistem. Skill newsroom-auto-pipeline sudah ada di profil manager Anda.

Langkah 4.1: Pastikan Skill Terpasang

/opt/hermes/bin/hermes skills install newsroom-auto-pipeline

Langkah 4.2: Konfigurasi dan Jalankan Gateway di Profil manager

/opt/hermes/bin/hermes config set gateway.profile_routes '[{"name":"newsroom-owner","platform":"telegram","user_id":"253935953","chat_id":"253935953","profile":"newsroom"}]'

/opt/hermes/bin/hermes gateway start

Informasi: Profil manager ini memungkinkan Anda untuk memicu seluruh rantai agen hanya dengan mengirim pesan.

🔄 Fase 5: Cara Sistem Bekerja (Flow Visual)

Anda mengirimkan pesan ke grup Telegram, misalnya:

/autopipeline cerita inspirasi startup lokal di Sekadau

Berikut adalah apa yang terjadi selanjutnya:

📜 Fase 6: Kontrak Data (JSON Internal)

Setiap agen mengirimkan hasilnya yang dilengkapi dengan blok JSON tersembunyi untuk konsumsi sistem. Berikut adalah contoh kontraknya:

/* Raka (Research) */
{"stage": "research", "agent": "raka", "summary": "...", "output": {"sources": [...], "key_facts": [...], ...}, "next_agent_message": "..."}

/* Sari (Fact-check) */

🔧 Fase 7: Memastikan Sistem Stabil

Langkah 7.1: Pastikan Watchdog Berjalan

Sistem ini dilindungi oleh tiga skrip watchdog yang berjalan dari cron setiap 15 menit:

  • newsroom_pipeline_watchdog.sh: Merestart daemon pipeline jika mati.
  • newsroom_orchestrator_watchdog.sh: Memantau proses orkestrator.
  • newsroom_mention_reminder_watchdog.sh: Mengingatkan agen yang tertunda.

Langkah 7.2: Periksa Kesehatan Sistem

/opt/hermes/bin/hermes doctor

🛡️ Fase 8: Keamanan & Monetisasi

Sistem ini dilengkapi dengan newsroom-publishing-policy yang menetapkan 6 gerbang keamanan:

  1. Source Gate: Setiap klaim harus memiliki sumber yang dapat dilacak.
  2. Originality Gate: Salinan harus menambah nilai editorial.
  3. Copyright Gate: Semua media harus memiliki hak penggunaan yang jelas.
  4. Editorial Gate: Nada, struktur, dan fakta harus sesuai standar.
  5. Monetization Gate: Konten harus aman untuk iklan/sponsor.
  6. Human Approval Gate: Topik sensitif membutuhkan persetujuan manusia.
